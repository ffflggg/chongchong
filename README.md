# 桌宠爱心版（Desktop + Android）

一套项目，两个平台版本：
- **Windows 桌宠**（main.py / 打包exe.bat → 桌宠爱心版.exe）
- **安卓手机版**（android_app/ → Kivy → .apk，手机一键安装）

## 📱 安卓手机版（APK 一键安装）

安卓基于 Kivy 原生运行，爱心悬浮球入口，点击即面板，照片抠图离线可用：

1. 项目推送到 GitHub → **Actions** 页面运行 `Build Android APK`
   （workflow 已配置：Ubuntu + JDK17 + buildozer，自动出 APK）
2. Artifacts 下载 `pet-heart-apk/bin/桌宠*.apk` → 传到手机安装
3. 打开 APP：屏幕右侧**呼吸红心** → 点击打开操作面板
   - 📷 从相册选照片（numpy 离线抠图，不依赖网络）
   - 大小 / 提醒语音（系统女声 / 我的录音 / AI 变声）
   - ⏰ 待办：内容+时间+提前分钟，到点桌宠走到屏幕中心 + 中文播报
4.「✕ 收起面板」桌宠留在屏幕，爱心随时唤回

> 本地开发验证：`cd android_app && python main.py`（Kivy 桌面模式）

## Windows 桌宠（原功能）

上传一张图片 → 自动 AI 抠图识别主体 → 抠好的角色出现在桌面，可以跳舞、打招呼、
聊天（带对话框）、吃东西、睡觉、奔跑…… 动态动作很丰富，还能多只同屏。

## 功能

- **自动抠图**：基于 rembg（U2-Net 等深度学习模型）自动识别并抠出图片主体，
  生成为透明 PNG；模型不可用时自动降级为内置边缘填充抠图，离线也能用。
- **躯干识别动画**：自动分析主体轮廓，定位头/颈/腰三部分分割线，每个动作
  头部、上身、下身独立摆动，走路会摆臂、跳舞会摇头扭腰，动作更自然。
- **桌面宠物**：透明、无边框、始终置顶的窗口，角色显示在桌面上，脚下带
  柔和投影。
- **鼠标交互**：左键按住拖动位置；双击随机动作（带防抖）；**右键弹出红色
  波点 ins 风菜单**：动作 / 移动模式 / 让它说话 / 自动随机动作开关 / 移到
  屏幕中间 / 打开控制面板 / 换一张图片 / 关闭宠物 / 退出；**触屏/手机长按
  600ms 弹出同一个菜单**（按下后不移位即触发，拖动则取消）。
- **待办提醒（绑定本机时间）**：菜单「⏰ 待办提醒」→「➕ 新建待办」输入内容
  与时间（HH:MM，24 小时制），可设**提前 0/5/10/15/30/60 分钟**提醒；到点宠物
  会从当前位置**自动走到屏幕正中央**，弹出 ⏰ 气泡并**声音播报**，8 秒后静默。
  - 待办开关 ✔/✖ 直接在菜单点；删除全部一键清空。
- **提醒声音三选一**（菜单「🔊 提醒语音」）：
  - 🗣 **系统女声**：Windows 自带中文 TTS，离线可用
  - 🎤 **我的录音**：录 3 秒自己的声音，之后用它提醒你
  - 🤖 **AI 变声**：把录音实时变成萝莉音 / 大叔音 / 机器人音
  - 随时切换、可试听预览。
- **17 种动态动作**：发呆、跳舞、打招呼、挥手、聊天、吃东西、睡觉、跳跃、
  奔跑、走路、转圈圈、生气、打喷嚏、难过、魔法、隐身术、开心跳跃。
  - 每个动作都带表情粒子（音符🎵、Zzz💤、食物🍔、✨ 星光……）
  - 聊天/吃东西/睡觉等都带**白色对话框气泡**，逐字打字机效果
  - **隐身术是真的隐身**：渐隐到完全消失→保持隐形→再出现，无闪烁
- **自动互动**：开启"自动随机动作"后，宠物每隔几秒自己找乐子。
- **多宠物**：同屏多只，各跑各的。
- **大小可超小**：8%~230% 自由缩放，能缩成指甲大小贴在角落。
- **可爱控制面板**：粉嫩圆角的"云朵形"异形窗口（带小耳朵），不是普通
  四四方方的对话框哦。
- **无终端运行**：双击 `启动桌宠.vbs` 用 pythonw 后台启动，不弹黑窗口；
  也可用 `打包exe.bat` 打成单个 exe **直接发给别人用**（模型 u2netp 已内嵌，
  对方无需装 Python、无需联网）。
- **触屏友好**：触屏设备上长按宠物 600ms 即可打开功能菜单（与右键菜单相同）。
- 性能：字体/阴影/粒子全部缓存并限量，实测每帧渲染约 5ms，60fps 流畅。

## 安装

需要 Python 3.10+（已在 3.13 验证）。国内建议用清华镜像源：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

说明：首次使用会自动下载抠图模型（u2net 约 170MB，u2netp 约 5MB），
下载需要联网；之后抠图结果会缓存到 `cache/` 目录。

## 使用

```bash
python main.py        # 带终端窗口运行
```

启动后屏幕右侧出现一颗**呼吸的爱心悬浮球**（可按住拖动位置）：

- **点击爱心** = 打开操作面板；**再点一下** = 隐藏面板（桌宠继续留在桌面）
- 面板里选图抠图后，桌宠**直接出现在桌面**
- 面板右上角 ─ 最小化到托盘 / ✕ 退出全部；托盘图标也能唤回面板
- 桌面宠物上：右键（触屏长按 600ms）打开波点菜单：动作 / 待办提醒 / 语音设置 / 换图……

想完全无窗口？双击 **启动桌宠.vbs** 后台启动，同样爱心入口。

1. 点击爱心 → 面板出现 → 点击 **🌈 选择图片 · 自动抠图**（或直接把图片拖进窗口），等待提示"抠图完成"。
2. 桌宠立即出现在屏幕底部（带阴影、走/跑会自动摆臂扭腰），面板可点爱心隐藏。
3. 右键点击宠物（触屏则**长按 600ms**），打开红色波点菜单：动作 / 移动模式 / 让它说话 / 待办提醒 / 换一张图片……
4. 面板右上角 ✕ 退出全部；宠物右键菜单可单独关闭。

## 分享给别人（手机/微信发送 exe）

1. 双击 `打包exe.bat`，等待生成 `dist\桌宠爱心版.exe`（首次需联网装 pyinstaller）。
2. 用微信/QQ 把 exe 发到手机，**转发到对方电脑**后双击即用。
3. 对方**无需安装 Python、无需联网**：双击 → 爱心悬浮球出现 → 点爱心设置 → 桌宠上桌。
4. 手机上提醒：手机系统本身跑不了 Windows 程序，需在电脑上双击运行。

> 提醒：单文件 exe 首次运行解压需要几秒，属正常现象。

## 文件结构

```
main.py         入口：爱心悬浮球 + 面板 + 托盘 + 提醒调度
heart_entry.py  爱心入口悬浮球（点击开/关面板，可拖动）
reminder.py     待办提醒（时间调度/TTS录音/变声/播放）
control_panel.py 控制面板（异形可爱窗口/选图/抠图/动作/多宠物）
cutout.py        抠图（rembg + 内置降级 + 躯干分割探测）
pet_window.py    桌宠窗口（躯干动画/气泡/拖动/菜单）
animations.py    全部动作定义
启动桌宠.vbs      无黑窗口后台启动（pythonw）
打包exe.bat      一键打包成无终端 exe
config.json      配置（自动保存你的设置）
cache/           抠图结果缓存
```

## 常见问题

- **模型下载失败**：网络问题。可换 `u2netp`（更小）再试，或确保能访问 GitHub。
- **手动兜底抠图**：背景较单纯的图片（纯色/相近色）效果够用；复杂背景请
  使用 rembg 模型路径的网络。
- **关闭面板即退出全部宠物**：面板右上角关闭 = 整体退出；想单独关某个宠物，
  在宠物上点右键 →「关闭这个宠物」。
